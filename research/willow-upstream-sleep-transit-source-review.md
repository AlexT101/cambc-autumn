## Blocker: zero HP is not certified native death

`bot.cpp:4383` skips `c.health[i] == 0` in an alive group after checking only current `health_round`. However `engine::camp_health` (`world.cpp:127`) maps both `not_found` and `not_in_vision` to `nullopt`, and `update_camp` converts that to zero and stamps `health_round=now` (`world.cpp:1742–1753`). The group epoch is already current before this loop. A failed/unavailable health read can therefore be accepted as a dead contributor without requiring its fresh asleep bit. The current visibility-board test before the old read explains the parent's ordinary dead-member inference, but does not turn the new certificate into an explicit successful death observation under partial/failed reads. The new helper even skips its own current visibility check in this zero case.

Smallest agreed repair: **reject every nonpositive/unproved member health in an alive group**, rather than skipping zero. Keep the early skip for a successfully recognized current cleared group. This adds no query or ledger, preserves the live single-Elk A309 opportunity, and conservatively misses partially dead groups. A richer death certificate is unnecessary for this first arm. Update the checkpoint's claim that current HP freshness alone proves dead members. Root independently found and agreed with this blocker.

## Checks that pass in source

- **Entry and continuation:** the fallback runs only in owned escape with `leave`, movement available, an already-ready home field, and a visible nearby potential pursuer. It handles original current-tile and reversing/non-progressing choices; it never replaces an originally home-progressing escape. Willow has no dash, so `StaticMap::from_ally_spawn()` is the same field returned by original `Pathing::to_ally_spawn()`. The original comparator is unchanged.
- **Enemy priority and legality:** alternatives come from existing legal neighboring stations, are strictly homeward, are not static camp tiles, and require no enemy/stun, damage, imminent damage or camp-imminent damage. Thus an alternative cannot add a modeled enemy hit to secure camp transit. There is no forced override when all alternatives fail. Native move refusal remains authoritative.
- **Fresh asleep evidence:** group mask/stamp reset before reads; only recognized alive/cleared group codes stamp the epoch; only successful current asleep results set bits. `update`/`observe` advance the epoch, so same-round re-observation expires old certificates. Partial failed reads cannot fabricate a living asleep bit. Index≥64, unseen, stale, awake and respawning contributors reject. This protection becomes complete for the intended conservative admission once the zero-HP bypass is removed.
- **Reserve:** each ray starts with the entry strikers, then accumulates the union of additional strikers reaching any ray point. Coordinate-based deduplication is valid for the same fixed static member; no member span survives a later index lookup. Union Strength times `(steps+1)` overcounts rather than undercounts camp hits along that ray, includes entry, rejects HP equality, and gives no mitigation/tank/heal credit. Bounds, open terrain, current blockers and static camp-tile checks certify an actual straight exit instead of an invalid off-map geometric exit. It is a camp-only bailout reserve, not a guarantee against future enemy interception or full home-route damage.
- **Retry and actions:** failed movement reaches the existing `see_again`, which expires the epoch, refreshes vision/Safety and rebuilds stations. The next attempt cannot reuse the earlier living-sleeper certificate. No pointers cross that refresh. Successful movement refreshes and returns once. Ordinary ally healing stays before movement; no camp attack, stun or reset is introduced, and owned return prevents ordinary farming work afterward. The extra stale-world check is before action.
- **Bound:** only one selected alternative is certified per attempt; at most eight rays, each at most `max_camp_reach+1` (six on the current rules), with early aborts. Member deduplication adds a bounded scan of previous ray coordinates. There is no new board, path field or native camp/readiness query. Existing board tests and lazy static member-index misses still cost fuel and may allocate; this is a source bound, not a native fuel result. The original loop remains capped at nine attempts.

## Conservative misses and remaining validation

Selecting one finalist means a failed certificate can miss another viable homeward neighbor. Requiring the existing home field to be ready, rejecting static camp tiles, expiring all certificates on any observe, rejecting live indices≥64, and rejecting a sleeping but incompletely observed group are intentional conservative misses, not correctness blockers. A non-progressing economic route that is not owned `leave` is intentionally outside scope. The proposed zero-HP repair adds another conservative miss.

Changed print formats and argument order look consistent; compilation is still required. Native cost and actual A309–313 entry/continuation remain unverified.
