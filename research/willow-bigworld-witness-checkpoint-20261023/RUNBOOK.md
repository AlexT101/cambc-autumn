# Big World branch witness adapter

This directory is an isolated source/workspace scaffold for the single canonical337f physical-A replay. It reuses the replay harness wrappers, op counter, trace-data generator, and comparator. It does not use `setup_ws.py` or `trace_batch.py`; those select v38 and the latter deletes/replaces slot contents.

The requested source and emulator snapshots are pinned in `source-manifest.json` and `emulator-source-manifest.json`. `workspace/bots/willow337f-release/src` is pristine. `workspace/bots/willow337f-rec/src` is the recorder copy plus `harness_rec.h`. `workspace/bots/willow337f-trace/src` is the trace copy plus `harness_trace.h`, `harness_trace_data.h`, and bounded `BW-*` hooks. `workspace/bots/fixed-emulator/src` is the pinned emulator copy; its `RELEASE_CODE` marker makes the debug-engine run compile it as Release code. All bot copies are source-only and have no `.cambc` or inherited `compile_commands.json`.
