## One proposed refinement

Add a narrow stationary-work admission tier inside ordinary ranged farm, before the existing full-ranking fallback. Apply it both to the damaged crew incumbent and to a nonincumbent that failed solo affordability. Keep harmless admission first, all higher-priority heal/retreat/bank/capture decisions, target order and native action checks, and the ranked/shared/risky logic unchanged.

1. Require current live, already-awake work with recent observed group damage, an in-range positive-health member, and a visible living ally actually within basic reach of a current member. A different explicit ally claim does not qualify as working this group. This is a local economic reason to finish useful existing work, not guaranteed future DPS. Do not require that the ally has not acted: completing this turn does not imply abandonment next turn.
2. Preserve `taken(g)` for nonincumbents. Otherwise this becomes a new help-selection policy that bypasses the existing comparison with other work. Existing crew incumbents can continue their own shared job. No remote claimant, inferred location, future heal or future tank position qualifies.
3. Compute one conservative current-tile camp-phase charge for the attack batch. Sum static damaging members whose reach contains our tile, including the target group's sleepers and uncertain/dead-looking members; do not subtract a nearer ally, a proposed kill, stun, spell, reset or future shield. Actual owned Jungle/Durability mitigation is legitimate. Conservative inclusion avoids new native liveness probes and failed-read-as-dead assumptions. Reject current enemy/stun exposure under the existing Safety model; this is not a promise about unseen future enemies.
4. Require `health - phase_charge >= recall_health_fraction * max_health`. **Do not divide this immediate damage by camp_risk=.35**, which is an economic weight used in the full-clear model. Reevaluate next turn. This reserves current HP for continued decision-making; it is not a certified route out of a multi-tile camp band or a full-clear survival proof.
5. Failure falls through to the existing ranking/retreat decisions. Success permits the already selected attack batch without forcing a whole-map economic reevaluation merely because `memory.damage>0`. Keep claim/farm/crew writes identical to the existing successful passing path.

The first version should decline new sleeping-group starts. Their group-wide wake can affect nearby allies and is a distinct decision. Thus this refinement need not reproduce the historical B39 attack. Its purpose is recoverable ongoing work, not imitation of that move list. `fully_awake()` is a belief, not an exact native certificate: require current member observations/recent work and treat stale/unknown awake information as a refusal; do not reuse Willow's sleep-read epoch as if it were maintained for other champions.

Implementation predicates from existing fields: ordinary_ranged, `!banks_bag`, no siege, alive group, `c.state_round == world.round`, `c.fully_awake()`, `c.last_damaged_round >= world.round-1`, and at least one positive-health member with `health_round == world.round`, currently visible and within self basic range. The visible nonself ally must be alive, have `Channel::none`, no explicit different claim, and be within its basic range of a positive-health currently observed member. Use current basic reach, not a future dash or spell reach. `acted` is not an exclusion. For a nonincumbent, retain the original `taken(g)` exclusion; for an incumbent crew, the matching claim is legitimate. Decline the extra tier when there is no useful current worker, even if the remembered `memory.crew` remains true. Failed/partial reads can leave these fields as beliefs: this is not a new successful-native-awake certificate. Its independent raw exposure charge remains conservative even if that belief is wrong.

For that raw charge, iterate existing `map.groups_near(here,map.max_camp_reach)` once and each returned group's static members once; add `m.strength` whenever positive and `dist(here,m.pos) <= m.reach`. Do not skip a member on cached zero HP, group cleared/respawning state, sleep or unknown state. Multiply the sum by the already-read `soften`. Including dead/respawning camps is deliberately conservative and removes the need for new freshness ledgers/imports. Separately use the existing current-tile Safety threat evaluation and refuse any modeled hit or stun; do not subtract its ally-discounted camp component from the static sum. No future injury enters the reserve with a probability weight.

## Cost, activation and rejection cases

Compute the current-tile charge once, lazily only after cheap ownership/work gates; use existing local static group lookup and scalar state. Reuse the result across candidates. No new field/path search, persistent protocol, arrival forecast or per-target native import. Existing target enumeration can call its group predicate repeatedly, so cache group eligibility within that bounded attack list rather than repeating the same member/ally loop for each tile. Do not silently call `Safety::camp_damage` as the raw charge: safety.cpp1733 skips sleeping members, and preceding code reduces reach using nearer champions. Both are unsuitable for the independent exposure bound above. Safety caches may materialize work, so this is not claimed fuel-free.

A strict source bound is one local static-member traversal plus one existing threat evaluation per attack batch, and one work-predicate evaluation per distinct candidate group (the existing target list holds16 entries). The group predicate must not repeatedly run while the enumerator is considering more tiles than will fit that list: a small scalar memo keyed by group, or a two-stage list/filter preserving existing order, must make this bound true. If16 distinct groups are already memoized, conservatively decline the additional tier for other groups while retaining their original admission; this is a structural bound, not a fuel-dependent policy. Consume the shared `groups_near` scratch range fully before any nested lookup. No full nine-station guard or terrain cache is needed for the new test.

A mechanical activation: a1000HP ranged crew member has taken40 damage, currently has700HP, can deal55 useful damage to its existing awake camp, and a visible nonconflicting worker is in real basic reach. All possible current-tile strikers sum to80 after owned mitigation and no enemy threat applies.700−80 exceeds350, so it may keep working despite positive `memory.damage`; a solo-clear estimate of800 no longer vetoes this single turn. At400HP the same phase fails, so full ranking/withdrawal is reconsidered. An ally leaving does not invalidate the80 charge because it never borrowed that ally's protection.

This tier can still lose a better walking opportunity, keep working an eventually abandoned partial camp, or conservatively reject good work because dead strikers remain charged. Camps do not regenerate, but retained damage is not equivalent to captured income. Judge useful attacks, eventual captures/capital, recall/route activity and default-fuel rollovers together. A named-map win or lower damage alone is not a keep criterion. No extra trace pipeline is required before deciding whether to implement this bounded experiment.
