Two hypotheses are enough:

1. **Low useful service access favors an independent fourth worker.** Public damaging camp types/reaches, gold rewards, spawn/altar paths and nearby work geometry can predict opportunities for a healer to remain productive near an injured worker. Large area alone cannot: long return trips increase the value of avoiding recall, but also separate recipients. High camp density can create injury while removing safe support stations. A range5 camp already illustrates a geometric limit: a camp-free Willow station at distance6 cannot heal a melee worker at distance1 with range4. This is an access constraint, not permission to relax safety. Current Big World supplies a low-service/low-growth nomination; Hooks supplies actual useful healing, but its four-pick comparison has a different displaced role. Existing five-pick exact-source exports can reject the hypothesis if supposed accessible-work maps show little actual overlap, or if Willow's healing is followed by no extra work/shorter recovery relative to the old-worker control. Expanse already rejects a universal zero-gold-growth explanation.

2. **The revealed Vesper/Vendetta/HoR prefix increases the cost of losing an independent economic worker.** This is a matchup hypothesis about three known roles, not knowledge of Varg/Cassi or an enemy identity. The older Fish prefix accompanied Willow wins as well as losses. Test the same current-draft comparison against the recent forced roster and the historical Cassi-fourth/Ryth-fifth roster as separate cells; compare against existing nonmatching opponent compositions before claiming prefix specificity. If old draft wins equally outside the prefix, the prefix adds no demonstrated predictive value. If only the recent continuation loses, prefix3 is an intentionally broad proxy with false activations, not a recovered full-roster detector.

For offline stratification, begin with **one service-access feature and one travel feature**, not a search over named maps: the fraction of ordinary damaging work whose camp reach permits a camp-free heal station in principle, and existing spawn/camp/altar walking distances. Weight the first by economic reward as well as report raw counts; harmless gem clusters and inaccessible boss rewards must not masquerade as sustained service demand. Reach is only a necessary geometric screen: walls, other camps, actual work positions and heal LOS still matter. No cutoff is selected here. Reject a proposed cutoff on an unused map panel if it does not separate the draft treatment effect, even when it predicts raw healing volume.

Fuel boundary: `draft_selection.h` already scans cached public camp layout once for member/group density; that density selects Ryth versus Vendetta and is **not** a Willow service-demand measure. A future approved static summary can accumulate type/reach/reward totals in that bounded scan without fields, pairwise searches or live calls. Existing `draft.cpp:95–160` progressively builds path fields and attack masks under its fuel budget. Missing analysis cannot mean low demand, and a selector must not introduce a new fuel-dependent policy gate. Use those existing distances offline first; runtime use would require a deterministic availability contract rather than a fallback threshold on incomplete data.

Safer next step: retain the clean old-draft control, then qualify it broadly if the screen warrants it. An unconditional old-draft restoration is simpler than a fitted selector but still needs evidence across five-pick maps; the prefix child is a narrower, explicitly uncertain mitigation experiment. In parallel, repairing a demonstrated low-growth job cycle can benefit both Willow and Vesper without discarding useful support. Big World alone does not prove an alternative job was feasible, so Sol's allocation investigation should establish that opportunity cost. No new draft threshold, farming change or runtime is authorized by this note.
