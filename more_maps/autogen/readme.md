Generated maps, made by `tools/mapgen` (see its README): `cambc1/`, `bc26/` and `fcode/` are older
games' maps converted to cambc2, `vae/` maps sampled from a VAE. Each folder's `manifest.json` says
how each map was made. The arena plays them in runs that pick them, and on the ladder only when the
Settings say so (they would add fixtures for every pair of bots).
